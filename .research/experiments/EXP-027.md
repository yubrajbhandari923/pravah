# EXP-027 · EXP-015v2 decision stability with a COMMENSURABLE paired baseline (pre-registered fix)

## Hypothesis

H1-paired: for each of the 8 replicate design draws r, the 500 m vs 250 m mesh-induced displacement and |regret| measured ON DRAW r are no larger than the replicate-PAIR displacement and |regret| between independent draws. Both distributions then contain the same case-draw structure, so the test can fail. H0-paired: mesh-induced change exceeds the resampling distribution, i.e. 500 m is numerically inadequate for sensor decisions. Either outcome is a valid finding, and unlike stage 2 a deliberately broken mesh must fail this test.

## Motivation

F-035/R1 established that EXP-015 stage 2 could not test H1: every mesh selects from the same seed-101 design draws while each replicate uses a different draw, so the baseline carries a case-draw variance component the mesh comparison lacks and a one-sided mesh<=baseline test cannot fail. This variant makes the two distributions commensurable. Pre-registered BEFORE running, with the amended one-sided criterion stated up front (D-006) rather than repaired afterwards.

## Method

Stage 1 field verification (cheap): fingerprints/basis columns and K_eff at 500/250/125 m (dt fixed small) and dt 100/50/25 at 500 m; observed orders; mass closure; min concentration. Stage 2 decisions: same configs/design(seed101,6)/validation(202,6)/test(303,6 + 6 fresh 304 held for final) ensembles and noise seeds on every mesh; candidate sites fixed in UTM metres (lookup of cell per mesh, never cell indices); alpha FROZEN at Phase 2 results/geodesign/alpha_selected.json (0.01) for all meshes; budgets 3,5,8; greedy_total selection per config. Reference model = 250 m, dt 50 (125 m used only for stage-1 fields and 1 design case-set if budget allows). Metrics per config vs reference: exact overlap (Jaccard), mean/max nearest-site displacement via optimal assignment (metres), objective value on the reference design cases, regret = J_ref(layout_c) - J_ref(layout_ref), and test RMSE of layout_c evaluated on reference-mesh truths. Resampling baseline: R=8 replicate design ensembles (6 cases each, new case seeds 1101-1108, noise seeds disjoint) on the 500 m mesh, giving the distribution of the same displacement/regret between replicate layouts, and an epsilon-optimal set size (single-site swaps within one replicate-SD of the objective). Scheme axis (exponential vs vanleer) only if T-026 passes verification.

## Expected outcome

Field error halves-ish per refinement at order ~1.4; layouts at small budgets are near-ties so displacement can be large with small regret; regret decreasing with refinement.

## Success criteria

ONE-SIDED, stated before running (D-006). Per budget (3, 5) at noise fraction 0.05: compute mesh-induced 500 m vs 250 m displacement and |regret| ON EACH of the 8 replicate draws, giving 8 paired values; compute the 28 replicate-PAIR values between independent draws. 500 m is admissible only if the paired mesh-induced distribution is no larger than the replicate-pair distribution, judged by (a) median mesh-induced <= median replicate-pair AND (b) a one-sided Wilcoxon signed-rank or a reported percentile of the paired values within the pair distribution. Report the full paired distribution, not a single number. A deliberately coarsened control mesh (2 km) MUST fail this test; if it passes, the test is still non-falsifiable and the result is void.

## Stop conditions

Stop and report if the 2 km falsification control passes. Stop if any arm reuses test seed 303 (burned by stage 2) - the fresh held-out seed is 304. Do not change the criterion, budgets, seeds or meshes after seeing results; the criterion is already amended and dated, and no further amendment is permitted. Budget 8 at noise 0.05 is excluded in advance because eps_sd/J_ref = 1.01 there means the objective is not identifiable at 6 cases.
