# EXP-016 · EXP population-aware sensor placement: area vs population vs mixed vs capped objectives (pre-registered)

## Hypothesis

H1: on concentrated-population fixtures (one_town, separated_settlements, dense_core_sparse_surround, mixed_rural_urban) greedy layouts selected with population weight reduce test population-weighted RMSE relative to the area-weighted layout at equal budget; H1-null for the uniform fixture (weights equal, layouts must be identical: a sanity check). H2: region-wide (area) RMSE rises and the rise is larger in low-population cells; H3: attribution (local/external) error is not degraded beyond between-case variability; H4: the benefit shrinks or reverses when the test population field differs from the design one (overfitting to an assumed distribution). Negative or null results are valid.

## Motivation

Precision may be given up in sparsely populated cells. Existing metrics weight cells equally (study mask only). DesignOptions.weight and metrics.field_mse already accept a weight map, so population enters only as a weight, not in the transport physics.

## Method

Gate: use the mesh/dt configuration judged adequate by EXP-015 (default 500 m, dt 100 if EXP-015 shows decisions stable relative to resampling, else the finer one). Region Belauri; population fixtures from src/pravah/population.py (people per cell inside the study mask, fixed totals, seeds declared), 5 fixtures. Objectives (all MSE-based so a convex mix is itself one weighted MSE, units (ug/m3)^2 with no ad-hoc scale): area w=A_i*study_i/sum; population w=N_i/sum N; mixed w=(1-beta)w_area+beta w_pop with beta in {0.25,0.5,0.75}; capped population w=min(N_i, c*mean_N_in_study)/sum with c=3 (equity proxy, exposes a fraction of cells; not a measure of personal exposure). Baselines: random (n=20) and spread, same budgets 2,3,5,8 (candidate set and noise reps identical, Phase 2 ensembles seeds 101/202 for design/validation; alpha frozen at the Phase 2 value 0.01 for all objectives, with a validation-selected-alpha sensitivity rerun clearly labelled secondary). Test: 12 fresh scenarios (seed 305, noise seed 3500) disjoint from design/validation, never used for any choice. Evaluate every layout with every metric: pop-weighted RMSE, area RMSE, RMSE in the lowest-population quartile of study cells (the neglected-region error), worst-cell RMSE, held-out-sensor RMSE (block and random), local/external attribution error. Cross-fixture matrix: layouts designed on fixture X evaluated on fixture Y (overfitting check). Pareto: beta sweep 0,0.25,0.5,0.75,1 plotting test pop-RMSE vs area RMSE.

## Expected outcome

Layouts move toward settlements; pop-RMSE falls most for concentrated fixtures at small budgets; area and low-population RMSE rise; differences shrink as budget grows.

## Success criteria

Paired per-case differences (objective minus area baseline) with a percentile bootstrap interval over the 12 test cases (labelled as such, n small; SD reported separately); effect called resolved only if the interval excludes 0 for pop-RMSE and the same direction holds in >=75% of cases; cost reported as the area and lowest-quartile RMSE increase and attribution change; design objectives and beta/c frozen in the registered config before test evaluation (config hash recorded).

## Stop conditions

Stop and report if uniform-fixture layouts differ from area layouts (bug); stop if population weights are zero over the whole candidate neighbourhood; no reselection of beta, c, alpha or fixtures after test results are opened.
