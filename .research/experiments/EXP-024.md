# EXP-024 · INFRA HPC round-trip smoke test (not a scientific experiment)

## Hypothesis

Infrastructure test with no scientific hypothesis. A deterministic sum over 1..100000 returns the closed-form values when run on an allocated compute node and the artifact comes home with a matching sha256.

## Motivation

Verify the production submission mechanism before spending allocation on EXP-015 and EXP-016. Nothing here is a PRAVAH scientific result.

## Method

scripts/hpc_smoke.py reads configs/hpc_smoke.json (transferred in the bundle source snapshot) and computes sum(1..n) plus sum of squares. It compares both against the closed forms stored in the config and writes result.json plus a sha256 sidecar recording hostname and Slurm job id and timestamps and cwd and Python version. Submitted via research hpc submit using sbatch on partition defq with 1 CPU and a short walltime. CPU-only.
