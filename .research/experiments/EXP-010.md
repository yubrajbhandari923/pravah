- **What worked:** Identifiability flags fire for the confounded and no-arrival cases without a prior hiding them; noise is set relative to a documented signal scale; alpha frozen on validation before the test ensemble; raw rows saved
- **What did not work:** An upwind reference site at fixed budget is not a free win: it improves the boundary/external terms but costs interior coverage, so total and local error are larger than with eight interior sensors in this setup. Wind mismatch is not detected by any flag (see special/wind_mismatch.csv)
- **Interpretation:** In this idealised linear setting the local/external split is recoverable when the sensitivity matrix is well conditioned and fails (flagged) when plumes arrive late or are collinear; whole-boundary inflow bases are a poor stand-in for a distant localised source. None of this identifies real emitters.
- **Limitations:** Synthetic matched model (same solver/grid for truth and inference except the labelled special cases); 4 validation + 6 test cases and 3 noise draws; one demonstration geometry with the external source 1 km from the domain-A boundary; sd is a standard deviation; the confounded default needed a 5 m/s wind, 3.8 km upwind geometry and a dedicated layout
