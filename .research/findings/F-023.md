# F-023 · Toy population-aware design: benefit appears only at 3 sensors on a single concentrated town, costs 3x area error, vanishes by 5 sensors; layouts matter far more than the objective

## Statement

Synthetic 50x50 domain, 16 fresh test cases, alpha 0.1 frozen on validation (area objective). At budget 3 on one_town the population-weighted greedy layout lowers population RMSE 0.00130 -> 0.00080 (-39%; paired bootstrap interval over cases excludes 0) while area RMSE rises 0.00071 -> 0.00225 (+219%) and worst-cell RMSE 0.0035 -> 0.0107; mixed beta=0.5 gives the same trade (pop 0.00070), beta=0.25 returns the area layout (step response). At dense_core_sparse_surround budget 3 the population layout is WORSE on population RMSE (+0.00072, resolved). From budget 5 on no difference is resolved for any fixture; mixed_rural_urban and uniform never differ from the area layout. Random layouts are 25-40x worse than any greedy layout, spread 6-8x.

## Limitations

Synthetic Domain without geography, local sources only (attribution not evaluated: external component is zero by construction), fixed Phase-1 discretisation not yet justified by EXP-015 stage 2; 16 test cases, bootstrap intervals are over test cases not confidence intervals for new scenarios; population fields are synthetic fixtures; population-weighted mean is not personal exposure; only 1 fixture draw per type; greedy layouts are discrete so the beta Pareto is a step function; Belauri-scale EXP-016 not run
