# D-005 · FiPy regression gate is architecture-scoped: the 21 files / 0 differ requirement is binding WITHIN an architecture; the

## Decision

FiPy regression gate is architecture-scoped: the 21 files / 0 differ requirement is binding WITHIN an architecture; the x86_64 cluster gets its own committed baseline and the arm64 baseline stays authoritative for laptop work. Cross-architecture bit-identity is not achievable and is not required. No tolerance was loosened.

## Reason

EVIDENCE. (a) RUN-0052 (Intel Xeon Silver 4310) and RUN-0053 (AMD EPYC 7513) both give 21 files compared, 18 differ against results/solver-regression/before, with values bit-identical to each other (direct/fit_sensor_rmse 0.0009213998644646732 on both nodes). (b) RUN-0053 captured twice on one node: 21 files compared, 0 differ, so the solver is bit-deterministic on cluster hardware. (c) A local venv built at the lockfile's pinned numpy 2.5.3 reproduces 21 files compared, 0 differ on arm64, so dependency drift is NOT the cause. (d) The committed baseline was captured on Apple M2 (arm64/NEON); the cluster is x86_64 with OpenBLAS DYNAMIC_ARCH and AVX-512. MAGNITUDE. All differences are floating-point reassociation. Largest difference in a physical quantity is 5.0e-08 relative (direct/heldout_sensor_rmse); max_concentration differs by 1 ulp (1.7e-16). The two apparently large 5.9e-03 relative differences are in max_abs/max_rel_budget_residual, which are mass-conservation residuals of magnitude ~1.6e-14 relative: both runs conserve mass to 14 digits, so that 0.6% is variation in a cancellation artefact, not a change in physics. CONSEQUENCE. EXP-015 stage 2 is unaffected because every arm of that experiment runs on the same cluster architecture, so within-experiment comparisons stay exact. The ~5e-08 architectural floor must be reported as a limitation whenever cluster numbers are compared with Phase 1-3 numbers computed on the laptop.
