## Current finding (v2, after gate-05; exploratory)

Winds: constant (exactly constant, null control), drifting (benchmark steady westerly, ±10° per 48 h block), changing (veering).
Prior-based ridge (sd a_ref), medians, fixed m = 4, seed as unit. Branch A, preregistered σ:
- Elapsed time alone adds nothing: under the constant wind practical rank is identical at W = 6, 24, 168 h in every seed.
- Wind change adds rank: window gain (6 → 168 h) minus the constant-wind gain = +0.37 for veering (16 of 17 non-tied seeds,
  p = 3e-4, bootstrap CI 0.24–0.49) and +0.11 for drifting (p = 0.02). This is the hypothesis's first half; the second half
  (repeats under the same transport only reduce noise) is the constant-wind null.
- Sensor savings only with changing wind: at equal readings (8), N = 4 over 168 h beats an N = 8 snapshot only under veering, K = 4
  (9/1 seeds, p = 0.02); under the constant wind it is worse (1/9, p = 0.02).
- Matched budget at 168 h: more sensors win (K = 4: N = 8 vs N = 4 at B = 16 10/1 seeds, p = 0.01; vs N = 2 18/0).
- Errors: median source error / rms strength ≈ 0.6–0.9; practical rank ≥ 1 still means large per-mode error (audit finding 7).
- Not covered: held-out forecast/field evaluation, AR(1) noise, optimised sites (E06 module), 3σ rank threshold. These go to E08.

## Superseded: v1 rerun (2026-11-12, commit 0569822)

The v1 claims (monotone window effect, sensor savings) were overstated: the window effect was the drifting wind, and mean-based tables
were dominated by estimator blow-ups (gate-05). Kept for the record:

Branch A, preregistered σ, best m per cell, random nested sites:
- Practical rank and source error improve monotonically with window for every K, N. K = 4: mean practical rank 1.75 → 2.95
  (N = 8) and 0.70 → 1.55 (N = 2) from snapshot to 7 days.
- Longer window partly substitutes for sensors: K = 4, N = 4 over 168 h (rank 2.40, median rel. error 0.52) beats N = 8 snapshot
  (1.75, 0.90); K = 2, N = 4 over 24 h beats N = 8 snapshot.
- Matched budget B = 16 at W = 168 h: more sensors beat more readings per sensor (K = 2 median rel. error 1.36 / 0.64 / 0.61 for
  N = 2 / 4 / 8).
- Full practical rank is still rare (8 % of cells); K = 4 never reaches it with 2 sensors.
- Wind diversity: no detectable rank gain in 90–98 % of cells (sign test, 20 pairs). Weak contrast: 'steady_westerly' drifts up to
  ~30° between 48 h blocks; 'veering' turns 45° only during the first 12 h of each block.
