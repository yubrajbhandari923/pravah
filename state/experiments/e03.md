# E03 Static constrained source-strength inverse — research journal

Status: run at smoke scale; baseline NOT cleared.

## Current finding

With fixed non-optimised sensors, 32², 24 h window, known wind, perfect model: the weighted sensitivity matrix is rank deficient (tol 1e-8) in all 648 fits (K, n ∈ {2,4,8}, 3 seeds, 4 noise levels). Source strengths are not identifiable there; unregularised NNLS errors reach ~1e27. 130/648 fits return all-zero coefficients. Non-uniqueness is demonstrated by a K=4, 2-sensor case. Bug fixed along the way: rank_info now reports cond = inf unless rank equals the number of source columns.

## 2026-11-12 rerun at a_ref = 1 g/s (amendment A1)

Still rank deficient (tol 1e-8) in all 648 fits. Rank is scale-free, so the cause is structural: ≤ 8 fixed, non-optimised sensors
and a 24 h window. For K = 2, two of three seeds put every sensor outside the plumes (SNR 0–1e-6). Where sensors see
plumes (K = 4/8, SNR 1–3) the columns are still not separable within 24 h. The ridge NNLS field estimate beats the zero estimate in
63–85 % of fits. Next lever is sensor placement (E06) and longer windows (E05), not the estimator. Commit 04bbd28.
