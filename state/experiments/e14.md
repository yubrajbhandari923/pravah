# E14: Reliability diagnostics (plan 3)

**Question:** Can a method tell, without the truth, when its own map or forecast is unreliable?
**Design:** `docs/research/reliability-design.md`, committed alone in 33efe67.
- Eight truth-free diagnostics, computed from data before each 24 h block (early warning). Tests confirm they are
  unchanged when all truth is set to NaN.
- Labels: L1, the 1 h forecast is worse than persistence; L2, 90 % coverage is below 0.70.
- Thresholds are chosen on validation blocks only.

## 2026-11-14: 32² pilot (exploratory; 6 clusters; E12 wind errors plus noise ×2, AR(1) noise, omitted source)
Evidence: `reports/quarto/tables/e14-local-*`, `figures/e14-local-{roc,calibration}.png`. Commit 98f8bfa.
- **Early warning works only moderately.** For L1 (base rate 0.64), the best diagnostic is sensor skill vs persistence:
  within-config AUC 0.71 [0.64, 0.77], rising to 0.81–0.86 for large direction or timing errors.
  - Spread, fit and NIS: 0.65–0.67. Lag-1 innovation autocorrelation: 0.63.
  - For L2 (coverage failure) the best is 0.63–0.65.
- **Calibration:**
  - With the true wind, 90 % coverage is 0.91 (map24) and 0.995 (map_full), but 50 % coverage is only 0.44–0.47.
  - With the wrong wind it collapses: 0.07 for a 30° direction error, 0.22–0.35 for timing errors.
- **Honest negatives:**
  - Speed × 0.8 is undetectable: every residual diagnostic has AUC 0.46–0.57.
  - Omitting a source gives overconfident blocks that no diagnostic flags (forecast about 4× worse than persistence,
    NIS ≈ 0.8, lag-1 ≈ 0).
  - NIS misses AR(1) noise; lag-1 catches it.
  - Spread flags low-signal hours, not mismatch.
- **H2 partly refuted:** with σ known, the whitened sensor fit does warn (AUC about 0.78 for large wind errors). E12's
  "deceptive fit" concerned fit ratios.
- **Limits:** 6 dependent clusters; the within-config AUC is post hoc.

- **"Persistence" is an oracle bound:** it carries the true field forward in every cell, so no network can reach it.
- **E12:** the near-perfect fit (1.01–1.33) holds only for speed, +10° and AR 15° errors; others give 1.6–4.3. Source

  true-wind run. The common-bias silent failure is confirmed exactly.
- **E14:** an omitted source is unflagged only for random networks (the arm's designs knew the source). The
  within-config AUC lowers rather than raises the score.
- **E15:** the k = 2 tail gain is indistinguishable from chance (9 of 648 contrasts at 6/0, about 10 expected).
- **E16:** the K ×20 cell is only ×1.5 effective at 32².
- **E17:**
